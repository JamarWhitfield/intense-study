## Engineering Principles

- Write clear code before clever code.
- Measure before optimizing.
- Explain tradeoffs, not just solutions.
- Prefer small working systems over vague large ideas.
- Every important concept should become code, a note, a diagram, a benchmark, or a test.
- Keep the repository organized enough that another engineer can understand it quickly.
